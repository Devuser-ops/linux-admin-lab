# Linux User & File Permissions Lab

## Objective
Learn Linux file permissions and access control.

## Topics Covered
- Linux permission structure
- Read, Write, Execute
- chmod command
- File ownership
- User, Group, Others

## Practical Exercises
- Created sample server report files.
- Applied chmod 600 to server-report.txt.
- Applied chmod 644 to backup-report.txt.

## Commands Used
- ls -l
- chmod
- mkdir
- touch

## Result
Successfully configured and verified Linux file permissions.
